Spell Book Manager Conservative Compact Abbreviation Legend
============================================================

Purpose
-------
This file is not only a rename map. It is meant to make the compacted
ScriptCards source maintainable by giving each abbreviated variable/label a
plain-English note about where it is used and what it represents.

The compact source intentionally keeps player-facing text, D&D 5E sheet
attributes, Roll20 object properties, handout names, and stored JSON keys
readable. Most abbreviations in this file are internal ScriptCards variables,
CSS helpers, loop variables, temporary outputs, or helper labels.

General / Spell List State
--------------------------
AKnown   = AlreadyKnown
           Tracks whether a spell name has already been seen while building a
           spell list, so duplicate spell names are not shown multiple times.

ASMS     = AssignedSpellMuleString
           Comma-separated internal list of spell source character IDs assigned
           to the currently selected character. Built from class, inherited,
           direct, and character-specific assignments.

CMS      = CanMoveSpells
           Flag used to determine whether the current character/spell context
           should offer Move Spells in addition to Choose Spells.

CSpells  = CopySpells
           Internal display/output section for copy-spell buttons.

CSBText  = CopySpellButtonText
           Text used on copy buttons. May vary depending on whether copying to a
           character, spell book, NPC, or another spell source.

DSL      = DisplayedSpellList
           Tracks which spell list is currently being displayed, such as All
           Spells or a specific assigned spell source.

KSL      = KnownSpellList
           Working list of known/displayed spells used while building the spell
           list card.

KSNC     = KnownSpellNameCheck
           Normalized spell-name check value used for duplicate prevention.

SIdx     = SpellIndex
           Loop/index value used while iterating spell rows.

SLC      = SpellLoopCheck
           Temporary check value used while scanning spell rows.

SLevel   = SpellLevel
           Current spell level being processed/displayed.

SMID     = SpellMuleID
           Character ID of a spell source character currently being processed.

SMName   = SpellMuleName
           Display name of a spell source character after stripping the SBM_
           prefix where appropriate.

SSM      = SelectedSpellMule
           Currently selected spell source ID. Can be a specific source or ALL.

SSMN     = SelectedSpellMuleName
           Display name of the selected spell source.

ChName   = Character_Name

ChOut    = CharacterOutput

Player Spell Book Copy Flow
---------------------------
IPSB     = IsPlayerSpellBookCopy
           Flag used when the current copy flow is the player/character-facing
           Copy to Spell Book flow rather than the GM Copy Between Mules flow.

PSBCD    = PlayerSpellBookCopyDestination
           Reentry label/card for choosing the destination spell book assigned
           to the selected character. Player-facing text says Spell Book rather
           than mule.

PSBCS    = PlayerSpellBookCopySource
           Reentry label/card for choosing the source spell list after a
           destination spell book has been chosen. For players this is limited
           to the selected character's assigned spell sources; for GMs this can
           list all active SBM_ spell sources.

PSBCID   = PlayerSpellBookCopyCharacterID
           Character ID of the actual selected character whose spell book flow
           is being used. This is the character context that determines player
           permissions and assigned spell books.

PSBCt    = PlayerSpellBookCount
           Count of valid destination spell books found for the selected
           character. Used to decide whether to show the Copy to Spell Book
           button on that character's options card.

PSBRE    = PlayerSpellBookReentry
           Raw reentry value passed into the spell book copy destination card.
           Usually contains the selected character ID and page/start value.

PSBSP    = PlayerSpellBookSplit
           Temporary split result used to separate PSBRE into its character ID
           and page/start parts.

BPSBL    = BuildPlayerSpellBookList
           Helper label that builds either the destination spell-book list or
           the source spell-list picker for the Copy to Spell Book flow.

PSBLM    = PlayerSpellBookListMode
           Mode passed into BPSBL. DEST builds valid destination spell books;
           SOURCE builds valid source spell lists.

PSBIDs   = PlayerSpellBookMuleIDs
           Array of assigned spell-source IDs built from the selected
           character's assigned spell mule/source string.

PSBL     = PlayerSpellBookLoop
           Loop variable used while iterating PSBIDs or the valid SBM_ source
           list.

PSBSX    = PlayerSpellBookSourceExclude
           Mule/source ID excluded from the source list, normally the already
           selected destination spell book.

PSBAS    = PlayerSpellBookAllowedString
           Comma-wrapped list of IDs allowed by the current BPSBL mode. Used by
           validation so stale or hand-crafted reentrant buttons cannot copy to
           an unauthorized destination/source.

VPSBC    = ValidatePlayerSpellBookCopy
           Helper label that validates a destination or source ID against the
           currently rebuilt allowed list.

PSBA     = PlayerSpellBookAllowed
           Result flag set by VPSBC. 1 means the destination/source ID is valid
           for the current character and mode.

PSBCX    = PlayerSpellBookCheckExclude
           Excluded mule/source ID passed into VPSBC and then forwarded into
           BPSBL.

PSBDOK   = PlayerSpellBookDestinationOK
           GM-only destination permission flag. When a GM opens Copy to Spell
           Book from a character, destination spell books must still be assigned
           to that character and controlled by one of that character's players
           or by all.

PSBCtrls = PlayerSpellBookCharacterControllers
           Array of the selected character's Roll20 controlledby entries. Used
           for GM destination filtering so the GM sees that character's player-
           controlled spell books, not every assigned SBM_ source.

PSBCtrlLoop = PlayerSpellBookControllerLoop
           Loop variable used while checking whether a candidate destination
           spell book shares a controller with the selected character.

SPSBD    = SetPlayerSpellBookDestination
           Reentry label that stores the chosen spell book destination and then
           moves to the source-list card.

SPSBS    = SetPlayerSpellBookSource
           Reentry label that stores the chosen source spell list and then moves
           into the normal spell-list/copy flow.

MCDID    = MuleCopyDestinationID
           Destination character ID for copy operations involving spell sources
           or spell books.

MCSID    = MuleCopySourceID
           Source character ID for copy operations involving spell sources or
           spell books.

MCDN     = MuleCopyDestinationName
           Display name for the selected destination, usually with the SBM_
           prefix stripped before being shown in card titles.

IMCM     = IsMuleCopyManager
           Flag used when the copy flow is copying to a mule/spell source rather
           than directly to a normal character.

Miscellaneous
-------------
SATd, SHTd, SITd, SNTd
           The lowercase d suffix means "table data cell" CSS. These are CSS
           snippets for different cells inside spell-list rows.

CCe, CSe
           Lowercase e suffix is used where the abbreviation would otherwise
           collide with another name. These are still CSS helper variables.

Notes for Future Maintenance
----------------------------
- If a variable is only used to build HTML/CSS, it is usually safe to rename as
  long as every reference is changed.
- Do not rename D&D 5E sheet attribute names such as spellname, spelllevel,
  spellconcentration, npcspellcastingflag, or repeating section names.
- Do not rename Roll20 object properties such as controlledby, gmnotes, notes,
  character:name, or ability/action fields.
- Do not rename player-facing button text unless the actual UI wording should
  change.
- For the compact release, include this legend beside the source so future
  maintainers can read the abbreviated version without reverse-engineering it
  from context alone.
