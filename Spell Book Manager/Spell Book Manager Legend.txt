Spell Book Manager Conservative Compact Abbreviation Legend
============================================================

Purpose
-------
This file is not only a rename map. It is meant to make the compacted
ScriptCards source maintainable by giving each abbreviated variable/label a
plain-English note about where it is used and what it represents.

The compact source intentionally keeps player-facing text, D&D 5E sheet
attributes, Roll20 object properties, handout names, and stored JSON keys
readable. Most abbreviations in this file are internal ScriptCards variables,
CSS helpers, loop variables, temporary outputs, or helper labels.

General / Spell List State
--------------------------
AKnown   = AlreadyKnown
           Tracks whether a spell name has already been seen while building a
           spell list, so duplicate spell names are not shown multiple times.

ASMS     = AssignedSpellMuleString
           Comma-separated internal list of spell source character IDs assigned
           to the currently selected character. Built from class, inherited,
           direct, and character-specific assignments.

CMS      = CanMoveSpells
           Flag used to determine whether the current character/spell context
           should offer Move Spells in addition to Choose Spells.

CSpells  = CopySpells
           Internal display/output section for copy-spell buttons.

CSBText  = CopySpellButtonText
           Text used on copy buttons. May vary depending on whether copying to a
           character, spell book, NPC, or another spell source.

DSL      = DisplayedSpellList
           Tracks which spell list is currently being displayed, such as All
           Spells or a specific assigned spell source.

KSL      = KnownSpellList
           Working list of known/displayed spells used while building the spell
           list card.

KSNC     = KnownSpellNameCheck
           Normalized spell-name check value used for duplicate prevention.

SIdx     = SpellIndex
           Loop/index value used while iterating spell rows.

SLC      = SpellLoopCheck
           Temporary check value used while scanning spell rows.

SLevel   = SpellLevel
           Current spell level being processed/displayed.

SMID     = SpellMuleID
           Character ID of a spell source character currently being processed.

SMName   = SpellMuleName
           Display name of a spell source character after stripping the SBM_
           prefix where appropriate.

SSM      = SelectedSpellMule
           Currently selected spell source ID. Can be a specific source or ALL.

SSMN     = SelectedSpellMuleName
           Display name of the selected spell source.

SMRAR    = SkipMoveRowAttributeRename
           Label used in TransferSpell after copying/moving a repeating spell
           row. Skips the row-prefix attribute rename when the source and
           destination prefixes are already the same, or when no matching
           attributes were found.

SMMO     = SetMoveMode
           Reentry label used by the Move Spells button. It bypasses Choose
           Spells and assigned spell book source-selection logic so the selected
           character's own sheet spell rows are used as the move source.

ChName   = Character_Name
           Current character display name used in menus/cards.

ChOut    = CharacterOutput
           Accumulated output for a character-selection list.

           Counter used while building character selection rows.

ChBG     = CharacterButtonBG
           Alternating/background color used for character picker buttons.

ChRowBG  = CharacterRowBG
           Row background color used while rendering character picker rows.

Mule Copy Manager Flow
----------------------
SMCM     = SetMuleCopyMode
           Helper label that initializes the shared mule-copy flags before
           choosing a destination or source mule.

MCCD     = MuleCopyChooseDestination
           Reentry label for the Copy Between Mules destination picker. It now
           sets MCPM to DEST and jumps into the shared MCPP picker page.

SMCD     = SetMuleCopyDestination
           Reentry label that stores the selected destination mule and then moves
           to the source picker.

MCCS     = MuleCopyChooseSource
           Reentry label for the Copy Between Mules source picker. It now sets
           MCPM to SOURCE and jumps into the shared MCPP picker page.

SMCS     = SetMuleCopySource
           Reentry label that stores the selected source mule and enters the
           normal spell-list copy flow.

MCPP     = MuleCopyPickerPage
           Shared picker page used by both MCCD and MCCS. DEST mode lists
           possible destination SBM_ mules. SOURCE mode lists source SBM_ mules
           while excluding the already selected destination.

MCPM     = MuleCopyPickerMode
           Mode used by MCPP. DEST builds the destination picker. SOURCE builds
           the source picker.

MCPT     = MuleCopyPickerTitle
           Title passed to OpenSBMCard by the shared mule-copy picker page.

MCPE     = MuleCopyPickerEmptyText
           Empty-list message shown by the shared mule-copy picker page.

Player Spell Book Copy Flow
---------------------------
IPSB     = IsPlayerSpellBookCopy
           Flag used when the current copy flow is the player/character-facing
           Copy to Spell Book flow rather than the GM Copy Between Mules flow.

           Reentry label that loads the single spell book assigned to the selected
           character and jumps directly to source selection. Player-facing text
           says Spell Book rather than mule.

           Reentry label/card for choosing the source spell list after the
           character's assigned spell book has been loaded. For players this is
           limited to the selected character's assigned spell sources; for GMs
           this can list all active SBM_ spell sources.

           Character ID of the actual selected character whose spell book flow
           is being used. This is the character context that determines the
           assigned spell book destination and the normal assigned spell sources.

           Count of active assigned spell book destinations found for the
           selected character. This should normally be 0 or 1 and is used to
           decide whether to show the Copy to Spell Book button on that
           character's options card.

           Temporary character ID extracted from the selected character's single
           assigned spell book setting. Used when normal Choose Spells is gated
           through that assigned spell book.

SBCM     = SpellBookChooseMode
           Flag set when normal Choose Spells has been redirected to the
           character's assigned spell book instead of the normal spell-source
           picker. Used mostly so the SpellList back button returns to the
           character options card instead of reopening the skipped source picker.

           Raw reentry value passed into the spell book copy destination card.
           Usually contains the selected character ID and page/start value.

PSBSP    = PlayerSpellBookSplit
           Temporary split result used to separate PSBRE into its character ID

           Helper label that builds either the single assigned destination spell
           book or the source spell-list picker for the Copy to Spell Book flow.
           DEST mode is based on the selected character's spellbook JSON setting,
           not Roll20 controlledby. SOURCE mode uses the character's assigned
           sources for players and all active SBM_ sources for GMs.

           Mode passed into BPSBL. DEST builds the assigned spell book
           destination; SOURCE builds valid source spell lists.

PSBIDs   = PlayerSpellBookMuleIDs

PSBAS    = PlayerSpellBookAllowedString

Miscellaneous
-------------
SATd, SHTd, SITd, SNTd
           The lowercase d suffix means "table data cell" CSS. These are CSS
           snippets for different cells inside spell-list rows.

CCe, CSe
           Lowercase e suffix is used where the abbreviation would otherwise
           collide with another name. These are still CSS helper variables.

Notes for Future Maintenance
----------------------------
- If a variable is only used to build HTML/CSS, it is usually safe to rename as
  long as every reference is changed.
- Do not rename D&D 5E sheet attribute names such as spellname, spelllevel,
  spellconcentration, npcspellcastingflag, or repeating section names.
- Do not rename Roll20 object properties such as controlledby, gmnotes, notes,
  character:name, or ability/action fields.
- Do not rename player-facing button text unless the actual UI wording should
  change.
- For the compact release, include this legend beside the source so future
  maintainers can read the abbreviated version without reverse-engineering it
  from context alone.
